# Checklist — Analysis Exit

> **Gate for:** `Analysis` → `Planning` · run by orchestrator at [business-analysis](../Workflows/business-analysis.md) exit. All boxes or no exit.

## Content
- [ ] S01: problem, who, why-now — no solutioning
- [ ] S02: ≥1 measurable goal with success metric
- [ ] S03: every requirement in [product-requirement](../Templates/product-requirement.md) format, stable IDs
- [ ] S03: every requirement has ≥1 falsifiable AC (no *fast/easy/intuitive/properly* unquantified)
- [ ] S03: non-goals listed
- [ ] S04: every item tagged `assumed` XOR `confirmed`; confirmations cite source (user answer / evidence)
- [ ] S06: initial risk register seeded

## Research
- [ ] Every S02 goal → ≥1 S05 theme OR `no-research-needed` marked
- [ ] Every S05 theme cites ≥1 resolvable source; zero unverifiable citations
- [ ] Evidence contradictions listed openly (none smoothed over)
- [ ] Evidence contradicting the request's premise → flagged in S05 + S16 (Planning input)

## Process
- [ ] Zero unresolved `blocking` open questions (answered or converted to accepted assumption via user)
- [ ] Scope class recorded; split recommended if `large` across unrelated areas
- [ ] Open S16 `Affects: S01–S06` entries addressed or explicitly deferred
- [ ] S16 stage-exit entry written
